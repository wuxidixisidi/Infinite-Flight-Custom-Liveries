# Пользовательские ливреи для Infinite Flight

> [!IMPORTANT]
> Эти пакеты предназначены **только для iOS**. Учётная запись Infinite Flight должна иметь доступ к **Scenery Editor**, поскольку пакет замены импортируется через этот редактор. Каждый пакет заменяет однотонную белую ливрею **Generic** соответствующего самолёта. Не распаковывайте загруженный ZIP-файл. После импорта полностью закройте Infinite Flight через переключатель приложений iOS, снова запустите игру и выберите заменённую ливрею **Generic**.

В этом репозитории размещены пользовательские ливреи для Infinite Flight, созданные сообществом.

Выход новых официальных ливрей может занимать много времени, а некоторые старые самолёты получают мало новых ливрей или не получают их вовсе. Цель проекта — расширить выбор за счёт малоизвестных авиакомпаний, исторических операторов, специальных схем окраски и редко обновляемых самолётов.

## Содержимое

- Ливреи, распределённые по типам самолётов
- Изображения для предварительного просмотра, если они доступны
- ZIP-пакеты для импорта на iOS
- Периодические дополнения, исправления и пересобранные пакеты

## Используемый инструмент

Пакеты создаются с помощью [Infinite Flight Livery Pipeline](https://github.com/kitalikesfreedom/infinite-flight-livery-pipeline), распространяемого по лицензии MIT. Все права на исходный инструмент принадлежат его автору.
