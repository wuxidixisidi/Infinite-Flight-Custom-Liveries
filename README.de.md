# Benutzerdefinierte Infinite-Flight-Lackierungen

> [!IMPORTANT]
> Diese Pakete sind **ausschließlich für iOS** bestimmt. Das Infinite-Flight-Konto muss Zugriff auf den **Scenery Editor** haben, da das Ersatzpaket darüber importiert wird. Jedes Paket ersetzt die einfarbig weiße **Generic**-Lackierung des jeweiligen Flugzeugs. Die heruntergeladene ZIP-Datei darf nicht entpackt werden. Nach dem Import Infinite Flight im iOS-App-Umschalter vollständig beenden, anschließend neu öffnen und die ersetzte **Generic**-Lackierung auswählen.

Dieses Repository enthält von der Community erstellte Lackierungen für Infinite Flight.

Die Veröffentlichung neuer offizieller Lackierungen kann längere Zeit in Anspruch nehmen. Einige ältere Flugzeugmodelle erhalten außerdem nur noch wenige oder keine neuen Lackierungen. Dieses Projekt erweitert die Auswahl um weniger bekannte Fluggesellschaften, historische Betreiber, Sonderlackierungen und selten aktualisierte Flugzeugtypen.

## Inhalt

- Nach Flugzeugtyp sortierte Lackierungen
- Vorschaubilder, sofern verfügbar
- Importierbare ZIP-Pakete für iOS
- Unregelmäßige Ergänzungen, Korrekturen und neu erstellte Pakete
