# Benutzerdefinierte Infinite-Flight-Lackierungen

[English](README.md) · [繁體中文](README.zh-Hant.md) · **Deutsch**

Dieses Repository enthält von der Community erstellte Lackierungen für Infinite Flight.

Die Veröffentlichung neuer offizieller Lackierungen kann längere Zeit in Anspruch nehmen. Einige ältere Flugzeugmodelle erhalten außerdem nur noch wenige oder keine neuen Lackierungen. Dieses Projekt soll die Auswahl durch Lackierungen weniger bekannter Fluggesellschaften, historischer Betreiber, besonderer Bemalungen und seltener aktualisierter Flugzeugtypen erweitern.

## Inhalt

- Nach Flugzeugtyp sortierte Lackierungen
- Vorschaubilder, sofern verfügbar
- Importierbare ZIP-Pakete für iOS
- Unregelmäßige Aktualisierungen und Korrekturen

## Installation

1. Das gewünschte Flugzeug und die gewünschte Lackierung auswählen.
2. Das entsprechende ZIP-Paket herunterladen.
3. Das Paket nicht entpacken.
4. Das ZIP-Paket mit einer unterstützten Importmethode in Infinite Flight importieren.
5. Infinite Flight bei Bedarf neu starten oder den entsprechenden Cache leeren.

Benutzerdefinierte Lackierungen sind normalerweise nur auf dem eigenen Gerät sichtbar. Andere Spieler im Mehrspielermodus sehen in der Regel weiterhin die ersetzte offizielle Lackierung.
