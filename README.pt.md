> [!IMPORTANT]
> Estes pacotes são **exclusivos para iOS**. A conta do Infinite Flight deve ter acesso ao **Scenery Editor**, pois o pacote de substituição é importado por meio desse recurso. Cada pacote substitui a pintura branca lisa **Generic** da aeronave correspondente. Não extraia o arquivo ZIP baixado. Depois da importação, feche completamente o Infinite Flight pelo seletor de aplicativos do iOS, abra o jogo novamente e selecione a pintura **Generic** substituída.

Este repositório contém pinturas personalizadas para Infinite Flight criadas pela comunidade.

Novas pinturas oficiais podem demorar bastante para serem lançadas, enquanto algumas aeronaves antigas recebem poucas ou nenhuma pintura nova. Este projeto procura aumentar a variedade com companhias aéreas menos conhecidas, operadores históricos, pinturas especiais e aeronaves que deixaram de receber atualizações frequentes.

## Conteúdo

- Pinturas organizadas por tipo de aeronave
- Imagens de pré-visualização quando disponíveis
- Pacotes ZIP importáveis para iOS
- Adições, correções e novos empacotamentos ocasionais

## Ferramenta utilizada

Os pacotes são preparados com o [Infinite Flight Livery Pipeline](https://github.com/kitalikesfreedom/infinite-flight-livery-pipeline), distribuído sob a licença MIT. Todos os direitos sobre a ferramenta original permanecem com o respetivo autor.
