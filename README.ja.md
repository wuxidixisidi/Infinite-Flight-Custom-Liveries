# Infinite Flight カスタム塗装

[English](README.md) · [繁體中文](README.zh-Hant.md) · [Deutsch](README.de.md) · **日本語** · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Português](README.pt.md) · [한국어](README.ko.md) · [Bahasa Indonesia](README.id.md)

> [!IMPORTANT]
> これらのパッケージは **iOS 専用**です。置換パッケージの読み込みには **Scenery Editor（シーナリーエディター）**を使用するため、Infinite Flight アカウントで同機能にアクセスできる必要があります。すべてのパッケージは、対象機体の白無地の **Generic** 塗装を置き換えます。ダウンロードした ZIP は解凍しないでください。読み込み後は iOS のアプリスイッチャーから Infinite Flight を完全に終了し、再起動して置き換えられた **Generic** 塗装を選択してください。

このリポジトリでは、コミュニティが制作した Infinite Flight 用カスタム塗装を公開しています。

公式塗装の追加には時間がかかることがあり、一部の旧型機には新しい塗装がほとんど追加されません。本プロジェクトは、知名度の低い航空会社、過去の運航会社、特別塗装、更新の少ない機体の塗装を制作し、ゲーム内の選択肢を増やすことを目的としています。

## 内容

- 機種別に整理されたカスタム塗装
- 利用可能な場合はプレビュー画像
- iOS 用インポート ZIP パッケージ
- 不定期の追加、修正、再パッケージ化
