# Infinite Flight Custom Liveries

**English** · [繁體中文](README.zh-Hant.md) · [Deutsch](README.de.md)

This repository contains community-made custom liveries for Infinite Flight.

Official livery updates for Infinite Flight can take a considerable amount of time, while some older aircraft receive few or no new liveries. This project aims to increase variety by creating liveries for lesser-known airlines, historical operators, special schemes and aircraft that are no longer regularly updated.

## Contents

- Custom liveries organised by aircraft type
- Preview images where available
- Importable ZIP packages for iOS
- Occasional updates and corrections

## Installation

1. Select the aircraft and livery you want.
2. Download the corresponding ZIP package.
3. Keep the package in ZIP format; do not extract it on your device.
4. Import it using a supported Infinite Flight custom-livery method.
5. Restart Infinite Flight or clear its relevant cache if necessary.

Custom liveries are generally visible only on your own device. Other multiplayer users will normally continue to see the original official livery that was replaced.
