> [!IMPORTANT]
> These packages are **for iOS only**. Your Infinite Flight account must have access to the **Scenery Editor**, which is used to import the replacement package. Every package replaces the aircraft's plain-white **Generic** livery. Keep the downloaded file in ZIP format. After importing it, completely close Infinite Flight from the iOS app switcher, reopen the game, and select the replaced **Generic** livery.

This repository contains community-made custom liveries for Infinite Flight.

Official livery updates can take a considerable amount of time, while some older aircraft receive few or no new liveries. This project aims to increase variety by creating liveries for lesser-known airlines, historical operators, special schemes, and aircraft that are no longer regularly updated.

## Contents

- Custom liveries organised by aircraft type
- Preview images where available
- Importable iOS ZIP packages
- Occasional additions, corrections, and rebuilt packages
