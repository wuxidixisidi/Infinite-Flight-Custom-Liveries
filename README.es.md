> [!IMPORTANT]
> Estos paquetes son **exclusivos para iOS**. La cuenta de Infinite Flight debe tener acceso al **Scenery Editor**, ya que el paquete de sustitución se importa mediante esa función. Cada paquete sustituye la librea blanca lisa **Generic** del avión correspondiente. No descomprimas el archivo ZIP descargado. Después de importarlo, cierra Infinite Flight por completo desde el selector de aplicaciones de iOS, abre de nuevo el juego y selecciona la librea **Generic** sustituida.

Este repositorio contiene libreas personalizadas para Infinite Flight creadas por la comunidad.

Las nuevas libreas oficiales pueden tardar mucho en publicarse y algunos aviones antiguos reciben pocas o ninguna actualización. Este proyecto busca ampliar la variedad con aerolíneas menos conocidas, operadores históricos, diseños especiales y aviones que ya no se actualizan con frecuencia.

## Contenido

- Libreas organizadas por tipo de avión
- Imágenes de vista previa cuando estén disponibles
- Paquetes ZIP importables para iOS
- Incorporaciones, correcciones y nuevos empaquetados ocasionales
